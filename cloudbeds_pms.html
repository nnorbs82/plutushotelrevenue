Software field note / Cloudbeds

Cloudbeds.

The interesting proposition is consolidation: a broad cloud stack that can reduce the number of moving parts a hotel has to coordinate.

The Cloudbeds question

How much should live inside one ecosystem?

For some hotels, having core functions brought closer together can make the technology stack significantly easier to manage. The trade-off is making sure each important workflow is strong enough for the property's needs.
