Publish through Pages CMS

The Blog is stored as Markdown in GitHub, but it can be edited through a normal browser interface. Pages CMS reads the repository configuration and writes changes back to GitHub.

Open Pages CMS ↗

  1. Sign in to Pages CMS with the GitHub account that has access to this repository.
  2. Open the Plutus Hotel Revenue repository and select the review/production branch you want to edit.
  3. Choose Blog Posts, then create a new post or edit an existing one.
  4. Add title, date, category, excerpt, cover image and the article body using the rich-text editor.
  5. Save. The GitHub workflow rebuilds the Blog archive and article pages automatically.

No password, API key or secret is stored in this public page.
